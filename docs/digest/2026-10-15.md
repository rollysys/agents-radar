## 1. 生态全景

AI CLI 领域已步入“平台化深耕”阶段。  
- **头部产品**（Claude Code、Codex）把重心从单纯的 Agent 能力转向生态扩展：Mods、MCP 等插件系统与企业级可观测性。  
- **桌面端/多端一致性** 与 **Windows 兼容性** 成为最热议的质量短板，几乎所有工具都有相关回归反馈。  
- **成本控制**（token 失控、缓存命中率、压缩策略）取代功能新增，成为社区最高频讨论主题。  
- **自托管 / 本地模型** 场景（Qwen Code、Pi、OpenCode）正形成以多 Provider 兼容和 KV‑cache 效率为核心的差异化路线。

## 3. 共同关注的功能方向

| 方向 | 说明 |
|------|------|
| **多端一致性** | 统一桌面、终端、移动端体验，解决 Windows 兼容性与 macOS/Linux 交互差异。 |
| **成本与性能** | token 失控、KV‑cache 命中率、压缩策略优化，降低 API 调用成本。 |
| **插件生态** | Mods、MCP、Skills 等插件系统的标准化与安全审计。 |
| **本地化与自托管** | 支持多 Provider（Qwen、Pi、OpenCode）本地模型部署，提升隐私与延迟。 |
| **可观测性** | 统一日志、监控、指标收集，满足企业级部署需求。 |
| **安全与权限** | 细粒度权限控制、Headless 运行可靠性保障。 |
